# Power Query Data Cleaning Project

## Overview

This project focuses on cleaning a messy dataset using Power Query in Power BI.

## Cleaning Tasks Performed

- Removed duplicates
- Handled missing values
- Fixed inconsistent formatting
- Cleaned text columns
- Corrected data types
- Removed unnecessary spaces

## Tools Used

- Power BI
- Power Query
- Microsoft Excel

## Files Included

- Raw messy dataset
- Cleaned dataset
- Power Query cleaning workflow screenshot

## Learning Outcome

This project helped me practice real-world data cleaning techniques and understand how to handle missing values 
in numerical and categorical columns.
